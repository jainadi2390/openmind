# Assets Directory

This directory should contain the application icons for different platforms.

## Required Icons

### macOS
- `icon.icns` - macOS application icon (512x512 or higher)

### Windows
- `icon.ico` - Windows application icon (256x256 or higher)

### Linux
- `icon.png` - Linux application icon (512x512 PNG)

### Tray Icon (Optional)
- `tray-icon.png` - System tray icon (22x22 or 16x16 PNG)

## Creating Icons

You can create these icons using:
1. Online tools like [iConvert Icons](https://iconverticons.com/)
2. Design tools like Figma, Adobe Illustrator, or Sketch
3. Command-line tools like ImageMagick

For a simple placeholder, you can use any 512x512 PNG image and convert it to the required formats.

## Recommended Design

The OpenMind logo should represent:
- Intelligence (brain, lightbulb)
- Transparency (clear, open design)
- Productivity (modern, professional)

Color scheme: Purple/Blue (#6366f1) to match the app theme.
